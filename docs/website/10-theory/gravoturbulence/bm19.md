The {cite:t}`Burkhart2018` and {cite:t}`BurkhartMocz2019` papers introduce
a forward model — in progenax we call it **BM19** — that turns four
cloud-scale parameters into a predicted dense-gas SFR:

```{math}
:label: bm19-forward
\bigl(\mathcal{M},\,b,\,\alpha,\,\eta_{\mathrm{survive}}\bigr)
\;\xrightarrow{\text{BM19}}\;
\bigl(\sigma_s,\,s_t,\,f_{\mathrm{dense}},\,f_{\mathrm{sub}},\,p,\,\zeta\bigr)
```

with $\mathcal{M}$ the sonic Mach number, $b$ the turbulence forcing
parameter, $\alpha$ the density-PDF tail slope, and
$\eta_{\mathrm{survive}}$ the post-feedback survival fraction. The
output is a tuple of cloud-state variables progenax stores in the
`BM19Result` PyTree.

This chapter is the forward chain end-to-end: each step's physics,
the parameter mapping, and the connection to observed SFR.

## The forward chain

The BM19 forward model has six numbered steps, each implementing a
single physical idea:

```{math}
:label: bm19-chain
\boxed{\;\;
\begin{aligned}
1. &\quad \sigma_s^2 = \ln(1 + b^2 \mathcal{M}^2) \quad \text{(turbulence)} \\
2. &\quad s_t = \bigl(\alpha - \tfrac{1}{2}\bigr)\,\sigma_s^2 \quad \text{(transition density; BM19 Eq.~2)} \\
3. &\quad f_{\mathrm{dense}} = \int_{s_t}^{\infty} e^s\,p_V(s)\,\mathrm{d}s \quad \text{(self-gravitating mass fraction)} \\
4. &\quad f_{\mathrm{sub}} = \eta_{\mathrm{survive}}\,f_{\mathrm{dense}} \quad \text{(post-feedback)} \\
5. &\quad p = 3 / \alpha \quad \text{(alpha-to-p mapping)} \\
6. &\quad \zeta = \mathrm{magnification\_factor}(p) \quad \text{(PP20 geometric SFR boost)}
\end{aligned}\;\;}
```

Each step uses one piece of the framework:

- **Step 1** uses [](density-pdf-fundamentals.md), {eq}`sigma-s`.
- **Step 2** uses the closed-form transition density {eq}`s-t`.
- **Step 3** uses the lognormal+power-law PDF and the FDF kernel
  ([](pdf-and-fdf.md)).
- **Step 4** applies a feedback survival factor $\eta_{\mathrm{survive}}
  \in [0, 1]$ — the fraction of dense gas that is not disrupted by
  early stellar feedback before it forms stars.
- **Step 5** applies the {cite:t}`Kritsuk2011` α↔p mapping.
- **Step 6** evaluates the PP20 magnification factor ([](pp20.md)).

## The four input parameters

```{list-table}
:header-rows: 1

* - Parameter
  - Range / typical
  - Physical meaning
* - $\mathcal{M}$
  - $[3, 30]$, typical $\sim 10$
  - Sonic Mach number; sets turbulence variance via $\sigma_s^2 = \ln(1 + b^2\mathcal{M}^2)$
* - $b$
  - $[1/3, 1]$
  - Forcing parameter: 1/3 solenoidal, 1 compressive, 0.4 natural mix
* - $\alpha$
  - $[1.5, 3.0]$ (Burkhart canonical window)
  - Power-law tail slope of the density PDF
* - $\eta_{\mathrm{survive}}$
  - $[0, 1]$
  - Fraction of dense gas that survives feedback to form stars
```

The {cite:t}`BurkhartMocz2019` α window has a clear physical interpretation:

- $\alpha = \alpha_0 = 3.0$ — turbulence-dominated, no significant
  collapse. $p = 1.0$, marginally collapsing radial profile.
- $\alpha = \alpha_{\mathrm{sat}} = 1.5$ — gravity-saturated, fully
  collapsing. $p = 2.0$, singular isothermal radial profile.

Real molecular clouds occupy the middle of this range,
$\alpha \sim 2.0$ corresponding to $p \sim 1.5$ and $\zeta \sim 1.4$.

## Connecting to observed SFR

The cloud-integrated SFR predicted by BM19 is

```{math}
:label: bm19-sfr
\frac{\mathrm{SFR}}{M_{\mathrm{cloud}}} \;=\;
\zeta\,\frac{\varepsilon_{\mathrm{ff,int}}\,f_{\mathrm{sub}}}{t_{\mathrm{ff}}(\langle\rho\rangle)}
```

Three quantities at the right combine to produce the canonical
"$\mathrm{SFR}/M_{\mathrm{dense}}$" diagnostic that observers measure:

```{math}
:label: sfr-mdense
\frac{\mathrm{SFR}}{M_{\mathrm{dense}}}
\;=\; \zeta\,\frac{\varepsilon_{\mathrm{ff,int}}}{t_{\mathrm{ff,dense}}}
```

with $M_{\mathrm{dense}} = f_{\mathrm{sub}}\,M_{\mathrm{cloud}}$ and
$t_{\mathrm{ff,dense}}$ the free-fall time of the *dense* gas (not the
mean cloud density). For typical Galactic cloud parameters
($\zeta \sim 1.4$, $\varepsilon_{\mathrm{ff,int}} \sim 0.01$,
$t_{\mathrm{ff,dense}} \sim 0.3$ Myr), $\mathrm{SFR}/M_{\mathrm{dense}}
\sim 5 \times 10^{-2}$ Myr$^{-1}$ — consistent with observed
dense-gas SFEs in nearby molecular clouds.

## Implementation in `gravoturb_fdf`

The clean-room package exposes the forward chain as **small, individually
testable functions** rather than one monolithic `bm19_pipeline` orchestrator
(that pattern, and its `BM19Result` PyTree, were intentionally dropped). Compose
them directly — each is `@jax.jit`-compatible and differentiable:

```python
import jax.numpy as jnp
from gravoturb_fdf.theory.bm19 import (
    sigma_s_squared, transition_density, f_dense_bm19_full, pdf_slope_to_radial,
)
from gravoturb_fdf.theory.pp20 import magnification_factor
from progenax.cluster.turbulence import spectral_slope_from_mach

mach, b, alpha = 10.0, 0.4, 2.0
sigma_s2 = sigma_s_squared(mach, b)             # ln(1+b²ℳ²)        ≈ 2.833
s_t      = transition_density(alpha, sigma_s2)  # (α−½)σ_s² (Eq. 2)  ≈ 4.250
f_dense  = f_dense_bm19_full(mach, b, alpha)    # mass-wtd dense frac ≈ 0.0568
p        = pdf_slope_to_radial(alpha)           # 3/α                = 1.5
zeta     = magnification_factor(p)              # PP20 ζ(p)          = √2 ≈ 1.414
beta     = spectral_slope_from_mach(mach)       # Kim&Ryu density slope ≈ 2.585

print(f"σ_s={jnp.sqrt(sigma_s2):.3f}  s_t={s_t:.3f}  f_dense={f_dense:.4f}  "
      f"p={p:.1f}  ζ={zeta:.3f}  β={beta:.3f}")
```

Note `β ≈ 2.585` here, **not** the ~4 (Burgers) value an earlier version of this
page printed: `spectral_slope_from_mach` returns the *density* power-spectrum slope,
which **flattens** with Mach per Kim & Ryu (2005) (see [](pdf-and-fdf.md) and the
[per-paper note](../../99-bibliography/per-paper/kim-ryu-2005.md)). To turn these
scalars into a 3D realization and read back the
realized dense fraction, use `gravoturb_fdf.field.pipeline.build_fdf_field`
(the AC6 cornerstone).

## Inference: what BM19 enables

The differentiability of {eq}`bm19-chain` end-to-end means BM19 can
sit inside an HMC posterior over cloud parameters. Given observational
constraints on:

- **$\sigma_s$ from column-density PDFs** (e.g. {cite:t}`Kainulainen2014`
  16-cloud sample).
- **SFR from infrared luminosities or YSO counts.**
- **Mean cloud density from extinction maps or molecular-line surveys.**

NUTS / NumPyro can in principle recover posteriors on $(\mathcal{M}, b,
\alpha)$ — the cloud's *turbulent state* — from *observed SFR*. The
differentiable forward functions above support this. The clean-room package
now ships a **differentiable physics-direct inference layer**
(`gravoturb_fdf.inference`): rather than differentiate the stochastic
simulator, it predicts the summary statistics analytically as smooth
functions of $\theta$ and differentiates *those* (log-density 2-point via
Gaussianization + counts-in-cells + a peaks-over-threshold density-tail
block), then samples with blackjax NUTS — recovering $(\mathcal{M},\alpha,\beta)$
on injection mocks, **including the density-PDF tail slope $\alpha$**. Because
the downstream star-sampling and CW04 $Q$ steps are non-differentiable, $Q$ is
a validation/demo diagnostic only (the earlier fitted `q_surrogate` prototype
was retired). Current validation status is documented at
[](../../50-validation/gravoturbulent-pp20.md).

## The 2026-04-28 PP20 fix and BM19

The transcription bug fix at [](pp20.md#historical-note-the-2026-04-28-transcription-fix)
affects step 6 of the BM19 chain — the `magnification_factor(p)` call.
Pre-fix, the bug produced ζ values that were silently wrong by
factors of order unity for typical $p \in [1, 2]$:

  - $p = 3/\alpha$
  - Buggy ζ
  - Correct ζ
  - Ratio
* - 3.0
  - 1.0
  - 4.30 (clamped)
  - 1.089
  - $3.95\times$ off
* - 2.0

All committed BM19 outputs from before 2026-04-28 carry these errors;
see [](../../90-development-log/2026-04-28-pp20-fix.md) for the full
history and which validation artefacts need regeneration.

## Domain of validity

1. **{cite:t}`BurkhartMocz2019` α window assumed.** Outside $\alpha \in
   [1.5, 3.0]$, the framework's mapping to PP20 ζ becomes uncertain.
   progenax allows external $\alpha$ values but warns at construction.
2. **Single-cloud assumption.** BM19 describes one cloud at one
   moment in time. Galactic-disc SFR predictions need an integration
   over the cloud-mass function — not currently included.
3. **No metallicity dependence.** {cite:t}`Moe2019` finds binary
   fractions are metallicity-dependent; cloud-PDF parameters likely
   are too. progenax does not currently include this.
4. **Static feedback.** $\eta_{\mathrm{survive}}$ is a single scalar,
   not a time-resolved feedback model. For evolved-cluster studies
   where feedback acts on a timescale comparable to $t_{\mathrm{ff}}$,
   a time-resolved framework is needed.

## References

The framework is {cite:t}`Burkhart2018` (Part I, "BM19" name)
extended by {cite:t}`BurkhartMocz2019` (Part II, the critical density for
star formation). The $\alpha$↔$p$ correspondence is
{cite:t}`Kritsuk2011`. The PP20 ζ that BM19 consumes is
{cite:t}`ParmentierPasquali2020`. The {cite:t}`FederrathKlessen2012`
density-PDF parameterisation underpins the whole framework. The
{cite:t}`Kainulainen2014` observational anchor at $p \approx 5/3$
(corresponding to $\alpha \approx 1.8$) is the strongest single
constraint on the BM19 input parameters from local-cloud observations.
