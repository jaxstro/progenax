# EFF profile validation

The EFF suite verifies the closed-form density, the inverse-CDF sampling, and the
ergodic (Eddington) velocity DF. Test file: `tests/validation/test_eff_physics.py`
(see the [test dashboard](test-dashboard.md) for the live per-suite count);
figures: `scripts/validate_eff.py`.

:::{admonition} Convention: γ is the 3-D density slope
:class: note
`EFFProfile(a, gamma, r_t)` uses **γ as the 3-D density slope** —
$\rho(r)=\rho_0(1+r^2/a^2)^{-\gamma/2}$, so $\rho\to r^{-\gamma}$ for $r\gg a$. This
is offset by $\sim1$ from {cite:t}`ElsonFallFreeman1987`'s *surface*-brightness
slope (the Abel projection of $r^{-\gamma}$ has surface slope $\gamma-1$). At
**γ = 5 the interior density shape is Plummer-like.** The finite EFF
model still has its imposed edge and truncated normalization; it is not
the untruncated Plummer distribution.
:::

:::{warning} Sharp truncation is mildly sub-virial
A retained sharp-edge $\gamma=3$ example has unscaled $Q\approx0.46$.
For a density with a nonzero edge value, the regular Eddington DF cannot
represent that constant edge offset. Positions from the prescribed finite
density and speeds from its numerically inverted DF therefore form a hybrid
approximation; numerical quadrature and clipping add separate errors. This
is not a statement that inversion is exact or that global virial balance
proves stationarity. A finite lowered DF such as King has a consistent
continuum cutoff. The mild-edge $\gamma=5$ example below has retained
$Q=0.502$; that measurement does not qualify arbitrary truncations.
:::

## Functional potential outside the density cutoff

`tests/unit/profiles/test_potential_exterior.py` separately compares the
functional EFF potential with $-GM/r$ outside $r_t$, using its infinity-zero
convention, gravitational constant $G$, and total truncated mass $M$. It checks values, exterior forces,
selected forward/reverse parameter derivatives, mass homology, and value
continuity through the last grid cell. Exterior gravity is not zero beyond a
density cutoff. These checks do not qualify the interior quadrature, boundary
derivative continuity, or the sharp-edge DF approximation above. See the
[potential convention](../10-theory/spatial-profiles/index.md#profile-vacuum-potential)
and the [functional API](../30-api/profiles.md#api-profiles-compute_profile_potential).

## Differentiability

The displayed derivatives concern selected density-shape and velocity-scale
observables. Full fixed-key sampler checks and population-expectation
derivatives have separate evidence. Gradient agreement alone does not
establish identifiability or calibrated HMC inference (see
[](king-profile.md#differentiability)).

:::{figure} figures/eff_gradient_validation.png
:label: val-eff-gradient
:width: 95%
:align: center

**Gradient validation (autodiff vs central finite difference).** (a)
$\partial\log\rho/\partial a$, (b) $\partial\rho/\partial\gamma$, (c)
$\partial\sqrt{\kappa}/\partial M_{\rm tot}$ (the velocity scale): autodiff (line)
and finite difference (circles) agree to **max rel err $5\times10^{-11}$,
$2\times10^{-11}$, $2\times10^{-6}$** for these observables. They are
not full-sampler derivative or joint-parameter recovery measurements.
:::

## How to run

```bash
# physics tests (~9 s on CPU)
pytest tests/validation/test_eff_physics.py -q

# regenerate the five figures with PASS/FAIL tables
python scripts/validate_eff.py
```

## What this suite does *not* test

- **Radial anisotropy** — the isotropic Eddington DF is covered; Osipkov–Merritt
  anisotropy is available via `EFFVelocityDF(anisotropy_radius=...)` and validated
  on the [OM validation page](rotation-om-anisotropy.md). Michie uses a
  different angular-momentum DF and is not an EFF OM oracle.
- **Multi-mass / unified lowered models** — see the
  [lowered-model-family roadmap](../10-theory/spatial-profiles/lowered-model-family.md).
