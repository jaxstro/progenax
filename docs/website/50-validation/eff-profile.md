# EFF profile validation

The EFF suite verifies the closed-form density, the inverse-CDF sampling, and the
ergodic (Eddington) velocity DF. Test file: `tests/validation/test_eff_physics.py`
(see the [test dashboard](test-dashboard.md) for the live per-suite count);
figures: `scripts/validate_eff.py`.

:::{admonition} Convention: γ is the 3-D density slope
:class: note
`EFFProfile(a, gamma, r_t)` uses **γ as the 3-D density slope** —
$\rho(r)=\rho_0(1+r^2/a^2)^{-\gamma/2}$, so $\rho\to r^{-\gamma}$ for $r\gg a$. This
is offset by $\sim1$ from {cite:t}`ElsonFallFreeman1987`'s *surface*-brightness
slope (the Abel projection of $r^{-\gamma}$ has surface slope $\gamma-1$). At
**γ = 5 the profile reduces exactly to Plummer.** The model is truncated at $r_t$.
:::

:::{warning} Sharp truncation is mildly sub-virial
The steep $\gamma=3$ default under **sharp** truncation ($r_t$ not $\gg a$) gives
an unscaled $Q\approx0.46$ — $\sim5$–8% sub-virial. This is an intrinsic property
of truncating an *empirical* (non-DF) profile, **not** an inversion error: the
Eddington inversion is exact, but a hard truncation removes high-energy orbits the
isothermal tail would supply. For a strict lowered-DF equilibrium use the
[King model](king-profile.md); for a near-virial EFF IC use mild truncation
($\gamma=5$, $r_t\gg a$), which the figure shows at $Q=0.502$.
:::

## Differentiability

EFF's structural parameters are differentiable, enabling gradient-based / HMC
inference. In particular **γ is a differentiable structural parameter** — the EFF
analogue of King's $W_0$ (both are differentiable; see
[](king-profile.md#differentiability)).

:::{figure} figures/eff_gradient_validation.png
:label: val-eff-gradient
:width: 95%
:align: center

**Gradient validation (autodiff vs central finite difference).** (a)
$\partial\log\rho/\partial a$, (b) $\partial\rho/\partial\gamma$, (c)
$\partial\sqrt{\kappa}/\partial M_{\rm tot}$ (the velocity scale): autodiff (line)
and finite difference (circles) agree to **max rel err $5\times10^{-11}$,
$2\times10^{-11}$, $2\times10^{-6}$**, so $(a,\gamma,M_{\rm tot})$ can be inferred
jointly.
:::

## How to run

```bash
# physics tests (~9 s on CPU)
pytest tests/validation/test_eff_physics.py -q

# regenerate the five figures with PASS/FAIL tables
python scripts/validate_eff.py
```

## What this suite does *not* test

- **Radial anisotropy** — the isotropic Eddington DF is covered; Osipkov–Merritt
  anisotropy is available via `EFFVelocityDF(anisotropy_radius=...)` and validated
  with the [Michie](../10-theory/velocity-dfs/michie-king.md) model.
- **Multi-mass / unified lowered models** — see the
  [lowered-model-family roadmap](../10-theory/spatial-profiles/lowered-model-family.md).
