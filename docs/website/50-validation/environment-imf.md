# Environment-dependent IMF validation

The cluster birth environment (cloud density $\rho_{\rm cl}$ in
$M_\odot\,\mathrm{pc}^{-3}$, metallicity $[\mathrm{Fe/H}]$ in dex,
embedded stellar mass $M_{\rm ecl}$ in $M_\odot$, and star-formation efficiency
$\varepsilon=M_{\rm ecl}/M_{\rm cl}$)
sets the IMF slopes via the {cite:t}`Marks2012` Fundamental Plane and the
{cite:t}`Jerabkova2018` per-cluster density relation, exposed through `BirthEnvironment`,
`env_to_imf_params`, `alpha3_marks_plane`, and `lowmass_slopes_metallicity`. Test
files: `tests/validation/test_environment_physics.py` (vs published tables) and
`tests/unit/imf/test_environment.py` (see the [test dashboard](test-dashboard.md)
for the live per-suite counts); figures:
`scripts/validate_environment.py`. Theory at [](../10-theory/imfs/environment.md).

:::{admonition} Key result: the predicted top-heaviness matches named globular clusters
:class: important
The Fundamental Plane reproduces the published high-mass slope $\alpha_3$ for the
four {cite:t}`Marks2012` Table 1 globular clusters within the retained test
allowance $|\Delta\alpha_3|<0.20$: NGC 7078 (M15) is the **most top-heavy** ($\alpha_3=0.84$ vs
published $0.76$), NGC 104 the least ($1.50$ vs $1.34$). The top-heaviness is driven
chiefly by **density** in the active plane interior — a 1-dex change in $\rho_{\rm cl}$ moves $\alpha_3$
by $0.40$ versus only $0.06$ for a 1-dex change in $[\mathrm{Fe/H}]$ (a $7{:}1$ ratio,
matching the Fundamental-Plane $\sin\theta/\cos\theta$). The metallicity-dependent
low-mass slopes reproduce the selected Table 4 anchors. Derivative checks cover
specified branch interiors and an opt-in smoothed mapping; they do not establish
global differentiability or identifiable recovery of the birth environment.
:::

## How to run

The [shared tutorial example](../00-getting-started/imf-sampling.md#environment-dependent-slopes)
executes all nine mapping-to-sampler routes at one retained input point.
Its regression checks the four slopes, three breaks, mass bounds and
the existing 10000-draw Marks-plane sample's dtype, shape and support.
Four additional Table-3 unit cases compare eager/JIT values and raw/JIT
forward/reverse derivatives with analytic chain derivatives, in active
unclipped interiors with computed density. They use the existing
`EXACT=1e-10` implementation budget. These checks do not recalibrate the
empirical relations or qualify boundaries and wider domains.

Registered source and local-derivation expressions now cover the four Table-3
laws, low-mass metallicity law, radius/density conversion, rounded coordinates
and high-mass laws. `test_environment_registry.py` compares symbolic host values
and first derivatives with unchanged eager/JIT kernels at the same `1e-10`
implementation budget. Exact substitution identities distinguish the rounded
mass constant from the direct density path and the printed Jeřábková Eq. 9.
Paper records are agent-checked transcriptions, not new researcher acceptance.
The [model card](#card-environment_imf) links equations, sources, kernels and tests.

```bash
# published-table checks and the turbulence tracing contract (float64)
JAX_ENABLE_X64=true PYTHONPATH=src .venv/bin/python -m pytest \
  tests/validation/test_environment_physics.py \
  tests/unit/substructure/test_q_baselines.py::TestBirthEnvironmentTurbulence -q

# shared executable example and local Table-3 implementation derivatives
JAX_ENABLE_X64=true PYTHONPATH=src .venv/bin/python -m pytest \
  tests/unit/imf/test_environment.py::TestEnvToIMFParamsAllModels -q

# registered algebra, values and local first derivatives
JAX_ENABLE_X64=true PYTHONPATH=src .venv/bin/python -m pytest \

# regenerate the five figures with PASS/FAIL tables
JAX_ENABLE_X64=true PYTHONPATH=src .venv/bin/python scripts/validate_environment.py
```

## Honest scope

- The GC $\alpha_3$ tolerance ($0.20$) is the existing test allowance, rather than
  a per-cluster published error bar. NGC 104 has $|\Delta|=0.16$.
- `alpha3_marks_plane` applies the **2014 erratum** (Marks et al. 2014, MNRAS 442,
  3315; PDF held): the threshold is $\hat x \ge -0.87$, not the $+0.87$ printed in the
  2012 Eq. 14/15 (a missing-minus-sign typo the authors did *not* use). With this
  correction the Marks plane and the Jeřábková density relation are close in the
  recorded comparison (@val-env-models); the GC anchors are unaffected because all four
  GCs lie at high density where $+0.87$ and $-0.87$ give identical $\alpha_3$.
- The turbulence diagnostics on `BirthEnvironment` (`turbulent_mach`, `sigma_ln_rho`,
  `spectral_slope`) are not inputs to $\alpha_3$. Existing unit tests check their
  adopted prescriptions. Four tracing regression cases compare eager/JIT values
  and raw/JIT forward/reverse derivatives of `sigma_ln_rho` with an analytic
  calculation, using default or explicit driving parameter $b$ and computed or
  overridden density. This is an API/derivative check, not empirical calibration
  of the density-dependent $b$ prescription. Evidence is recorded in
  `docs/reviews/birth-environment-contract-review.md`.
- Wider physical domains, higher derivatives and inference convergence remain
  unqualified. The default hard threshold and output clipping retain their
  boundary limitations; see the [theory page](../10-theory/imfs/environment.md).
