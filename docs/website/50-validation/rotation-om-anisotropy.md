# Rotation & anisotropy validation

Two kinematic structures layered on the isotropic ICs: **streaming rotation**
(an additive velocity transform) and **Osipkov-Merritt radial anisotropy** (a
velocity-DF shape). Test file:
`tests/validation/test_rotation_anisotropy_physics.py` (**10 tests**); figures:
`scripts/validate_rotation_anisotropy.py`. Theory at
[](../10-theory/velocity-dfs/rotation-anisotropy.md).

:::{admonition} Two routes to anisotropy — a clean contrast
:class: note
The `anisotropy_radius` $r_a$ realizes the Osipkov-Merritt profile
$\beta(r)=r^2/(r^2+r_a^2)$ **exactly**, via a velocity-direction *stretch* applied
to isotropic speeds (Merritt 1985, Eq. 15). This is the opposite of the
[Michie-King model](michie-anisotropy.md), whose self-consistent lowered DF gives
the *same target* but a $\beta$ **suppressed below** the OM ceiling. Same $\beta(r)$
goal; exact by post-hoc stretch, suppressed by the self-consistent cutoff.
:::

## What is verified

Each row maps to assertions in `test_rotation_anisotropy_physics.py`. **Measured**
values are regenerated by `scripts/validate_rotation_anisotropy.py`. Rotation is an
*additive* transform, so the added field $v_{\rm rot}=v_{\rm after}-v_{\rm before}$
is validated exactly (no isotropic-scatter noise).

```{list-table}
:header-rows: 1

* - Property
  - Tolerance (as tested)
  - Measured
  - Anchor
* - Solid-body $v_\phi(R)=\Omega R$
  - slope $=\Omega$ to $10^{-6}$
  - $0.300000$ (resid $3\times10^{-14}$)
  - $v_{\rm rot}=\Omega\times r$
* - Angular-momentum budget $L_z=\Omega\sum m R^2$
  - $10^{-6}$ rel
  - exact
  - rigid rotation
* - Rotation is purely azimuthal ($v_R$ unchanged)
  - $10^{-9}$ abs
  - unchanged
  - $\Omega\times r \perp \hat R$
* - Differential $v_\phi(R)=v_{\rm peak}\frac{R}{R_p}e^{1-R/R_p}$
  - $10^{-6}$ abs
  - max dev $<10^{-6}$
  - phenomenological curve
* - OM anisotropy $\beta(r)=r^2/(r^2+r_a^2)$ — Plummer
  - $<0.04$ per bin
  - max dev $0.024$
  - Merritt (1985) stretch
* - OM anisotropy $\beta(r)$ — EFF
  - $<0.05$ per bin
  - max dev $0.016$
  - same stretch
* - $r_a=\mathrm{None}$ is isotropic
  - $|\beta|<0.04$
  - $\beta\approx0$
  - no stretch
* - Differentiability ($\Omega, v_{\rm peak}, r_a$)
  - AD $=$ central-FD
  - rel err $3\times10^{-9}$, $7\times10^{-9}$, $8\times10^{-6}$
  - pure transforms + fixed-key stretch
```

## Figures

Generated by `scripts/validate_rotation_anisotropy.py` (PASS/FAIL per panel).

:::{figure} figures/om_anisotropy_beta.png
:label: val-om-beta
:width: 75%
:align: center

**Osipkov-Merritt anisotropy.** Both Plummer (circles) and EFF (squares) sampled
$\beta(r)=1-\sigma_t^2/2\sigma_r^2$ land **exactly** on the OM target
$r^2/(r^2+r_a^2)$ (max dev $0.024$, $0.016$), reaching $\beta=0.5$ at $r=r_a$. The
direction-stretch realizes OM exactly — unlike the self-consistent
[Michie-King](michie-anisotropy.md) $\beta$, which is suppressed below this curve.
:::

:::{figure} figures/rotation_velocity_field.png
:label: val-rotation-field
:width: 95%
:align: center

**Face-on velocity field.** (a) The isotropic IC has random in-plane velocity
directions (no net rotation). (b) After solid-body rotation $\Omega=0.3$ the
streaming field $v_{\rm rot}=\Omega\times r$ is coherent circulation (arrows
colored by $v_\phi$, all co-rotating).
:::

:::{figure} figures/rotation_solid_body.png
:label: val-rotation-solid
:width: 60%
:align: center

**Solid-body rotation.** The added streaming $v_\phi(R)$ is linear in cylindrical
$R$ with fitted slope $=\Omega=0.300000$ (residual $3\times10^{-14}$); the injected
angular momentum equals $\Omega\sum m R^2$ exactly.
:::

:::{figure} figures/rotation_differential.png
:label: val-rotation-diff
:width: 60%
:align: center

**Differential rotation.** The added $v_\phi(R)=v_{\rm peak}(R/R_p)e^{1-R/R_p}$
peaks at $R_{\rm peak}$ and decays inward and outward (a phenomenological curve,
not from a specific paper). Per-particle match to $<10^{-6}$.
:::

## Differentiability

:::{figure} figures/rotation_gradient.png
:label: val-rotation-gradient
:width: 95%
:align: center

**Gradient validation (autodiff vs central finite difference).** (a)
$\partial T_{\rm rot}/\partial\Omega$, (b) $\partial T_{\rm rot}/\partial v_{\rm peak}$,
(c) $\partial\langle v_r^2\rangle/\partial r_a$: autodiff and finite difference agree
to max rel err $3\times10^{-9}$, $7\times10^{-9}$, $8\times10^{-6}$. The rotation
amplitudes and the anisotropy radius are all differentiable for inference.
:::

## How to run

```bash
pytest tests/validation/test_rotation_anisotropy_physics.py -q   # 10 tests, ~7 s
python scripts/validate_rotation_anisotropy.py                   # 5 figures + PASS/FAIL
```

## What this suite does *not* test

- **Self-consistent rotating equilibria** — the rotation here is a streaming
  transform added to a non-rotating equilibrium, not a self-consistent rotating DF
  (that is part of the [lowered-model-family roadmap](../10-theory/spatial-profiles/lowered-model-family.md)).
