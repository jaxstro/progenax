# Michie-King anisotropy validation

The Michie (1963) radial-anisotropy term on King's (1966) lowered cutoff: a
self-consistent, radially anisotropic cluster model. Test file:
`tests/validation/test_michie_physics.py` (see the
[test dashboard](test-dashboard.md) for the live per-suite count); figures:
`scripts/validate_michie.py`. Theory at
[](../10-theory/velocity-dfs/michie-king.md).

:::{admonition} Key result: anisotropy is *suppressed* below Osipkov-Merritt
:class: important
The Michie-King DF $f \propto e^{-J^2/2r_a^2\sigma^2}\,[e^{-E/\sigma^2}-1]$ is **not**
a pure function of $Q=E+J^2/2r_a^2$ — the lowering term $-e^{-J^2/2r_a^2\sigma^2}$
depends on $J$ alone. Consequently the anisotropy $\beta(r)$ sits **below** the pure
Osipkov-Merritt ceiling $r^2/(r^2+r_a^2)$, increasingly so outward, and turns back
toward isotropy at the tidal boundary. We therefore validate the sampler against the
model's **own DF $\beta$** (a 2nd-moment oracle), not against the OM form. The theory
page already notes the DF "is not a function of one integral."
:::

## What is verified

Each row maps to assertions in `test_michie_physics.py`. **Measured** values are
regenerated by `scripts/validate_michie.py`. All use $W_0=7$, $r_c=1$, with
$r_a=8\,r_c$ for the anisotropic case (it truncates: $r_t/r_c\simeq56$) and
$r_a=10^4\,r_c$ for the isotropic limit.

## Differentiability

The Michie structural parameters are differentiable through the `diffrax` ODE solve
and the `jax.lax.scan` sampling, enabling gradient-based / HMC inference of the
anisotropic model.

:::{figure} figures/michie_gradient_validation.png
:label: val-michie-gradient
:width: 95%
:align: center

**Gradient validation (autodiff vs central finite difference).** $\partial(\text{obs})/\partial\theta$
for (a) $W_0$, (b) $r_c$, (c) $M_{\rm tot}$: autodiff and finite difference agree to
max rel err $1\times10^{-7}$, $1\times10^{-8}$, $7\times10^{-7}$, so the anisotropic
model can be fit jointly with the structural parameters.
:::

:::{note} Equilibrium-dispersion $\partial\sigma/\partial W_0$ for OED/Fisher (2026-06-17)
The OED/Fisher forward model differentiates the *equilibrium* dispersion
`jeans_dispersion` / `project_dispersion`, which interpolate a master radial table back
to the query radii. That back-interpolation was a piecewise-linear $C^0$ `jnp.interp`:
as the truncation radius $r_t(W_0)$ moved the table's grid nodes, the interpolant's slope
jumped at a fixed query radius and kinked $\partial\sigma/\partial W_0$, so a coarse
finite difference reported a $\sim 5\times10^{-3}$ inconsistency. The fix (ADR-0016) is a
monotone $C^1$ (PCHIP) back-interpolation, which removes the slope jump: the Michie-$W_0$
dispersion gradient is now FD-consistent ($5.1\times10^{-3}\to3.5\times10^{-4}$ at the gate
step), model-general across King/Michie/EFF/Plummer. **Caveat:** beyond $W_0\approx7$ (at
$r_a=5\,r_c$) the Michie model nears its mass-divergence ($r_t\to\infty$); the gradient stays
correct (a finite difference *converges* to autodiff as the step shrinks) but a fixed-step FD
is a poor truth-proxy there, so the gradient gate runs in the well-truncated $W_0=6$ regime.
:::

## How to run

```bash
# physics tests (~22 s on CPU)
pytest tests/validation/test_michie_physics.py -q

# regenerate the five figures with PASS/FAIL tables
python scripts/validate_michie.py
```

## What this suite does *not* test

  multi-mass generalization is part of the
  [lowered-model-family roadmap](../10-theory/spatial-profiles/lowered-model-family.md).
