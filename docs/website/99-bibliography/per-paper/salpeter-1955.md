# Salpeter (1955)

```{admonition} The luminosity function and stellar evolution
:class: note

**Authors.** E. E. Salpeter

**Reference.** *The Astrophysical Journal* **121, 161** (1955).

**DOI.** [10.1086/145971](https://doi.org/10.1086/145971)
```

## Abstract (paraphrased)

The original derivation of the stellar IMF as a single power law $\xi(m) \propto m^{-2.35}$ from solar-neighbourhood star counts. Combined the present-day mass function with stellar-evolution timescales to back out the birth-mass distribution. The Salpeter slope is the high-mass slope of all subsequent IMF parameterisations.
