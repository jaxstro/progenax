# Bibliography

This page renders progenax's full bibliography from
`references.bib`. Click any title for the source paper; click
`{cite}` keys throughout the docs to jump back here.

```{bibliography}

```

## Per-paper detail pages

For paper-by-paper detail (abstract, ADS / arXiv links, list of
progenax modules that cite it), see the
[per-paper detail pages](per-paper/index.md).

## Adding a new paper

1. Add a BibTeX entry to `docs/website/references.bib`.
2. (Optional) Add a per-paper detail page under `per-paper/` with
   abstract and cross-refs.
3. Use the new `{cite}` key in any chapter.

`references.bib` is the **single source of truth** for citations.
The bibliography page is autogenerated from it.
